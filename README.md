
# Queue Data Structure in C

## 📌 About This Repository
This repository contains 5 C programs based on the Queue Data Structure. These programs demonstrate basic queue operations and different applications of queues.

## 📚 Programs Included

### 1. Queue Using Array
- Implement a queue using an array.
- Enqueue (Insert an element).
- Dequeue (Delete an element).
- Display queue elements.

### 2. Queue Using Linked List
- Implement a queue using a linked list.
- Enqueue operation.
- Dequeue operation.
- Display queue elements.

### 3. Deque (Double Ended Queue)
- Implement a deque using an array.
- Insert elements from both front and rear.
- Delete elements from both front and rear.
- Display deque elements.

### 4. Reverse a Queue Using Stack
- Reverse the elements of a queue with the help of a stack.
- Demonstrates the use of two data structures together.

### 5. Generate Binary Numbers from 1 to N
- Generate binary numbers from 1 to N using a queue.
- Uses queue operations to generate binary sequences.

## 🛠️ Language Used

## 💻 Concepts Covered
- Queue Data Structure
- Array
- Linked List
- Stack
- Enqueue and Dequeue
- Deque Operations
- FIFO (First In, First Out)

The objective of this repository is to understand queue operations and their practical implementation using C programming.
